Frameworks built for this work

Production-tested frameworks developed and refined across multiple client engagements. Engagements that draw on them move faster and require less remediation.

Integration Layer

IntegrationEngine

Reusable integration framework for connecting BC to third-party platforms. Authentication, transformation, error handling, and retry logic as shared infrastructure — not rebuilt per engagement.

Data Migration Suite

SQL-Import + DataMover

SQL-based migration tooling handling extraction from any ODBC/OLE source, entry number renumbering, collision resolution across entities, and full sub-ledger preservation.

Upgrade Tooling

ALUpgradeTools

Purpose-built for NAV-to-BC migrations — object analysis, C/AL to AL conversion assistance, and validation frameworks for moving legacy codebases through the transition.

Observability

LoggingApp

Custom logging and observability framework for BC. Structured event capture, error tracing, and audit trail support beyond what native BC telemetry exposes.

Data Layer

sqlcore + SQLSearch

Core SQL connectivity library and search tooling for BC. Direct data-layer access patterns for migration, reporting, and integration work where standard AL table access is insufficient.

Delivery Pipeline

AL-Go + AppSource Framework

Full AL-Go pipeline setup covering multi-environment CI/CD, artifact signing, AppSource delivery targets with version and go-live controls, ALDoc documentation generation, and concurrency-safe deployment — including the separate migration app pattern that keeps AppSource packages clean.

FAQ

Common questions from partners

Will you compete for our clients?

No. I don't pursue managed services contracts or ongoing client relationships. I'm technical capacity for the specialized work — support relationships and referrals stay with you.

Can we present the work as our own?

Yes — white-label is one of four relationship structures I work under, alongside co-delivery, subcontractor, and referral. Which one fits depends on how visible you want me to be to the client.

How is billing structured?

Time & materials (billed through you or direct), a deferred retainer, timeboxed blocks, or project-based pricing with defined scope — see Engagement Models above for the full breakdown.

How fast can you start on an emergency escalation?

I keep short-notice and emergency slots open. Typical response is within 24 hours, with engagement starting within 1–2 days.

What migration sources do you support?

Any ODBC/OLE source — NAV, GP, Sage, QuickBooks, AS400, or a homegrown ERP — migrating into Business Central, including on-premises to SaaS.

Do you work within our existing CI/CD setup?

Yes — AL-Go and GitHub Actions pipelines, artifact signing, and AppSource delivery targets are all part of the standard tooling. I can also help set that up if it isn't in place yet.
